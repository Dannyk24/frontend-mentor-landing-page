# Frontend Mentor Landing Page Clone

This project is a **UI clone of the Frontend Mentor landing page**, built to practice layout, styling, responsive design and interactivity using **HTML and CSS and Javascript**.

⚠️ This project is for **learning and practice purposes only**.  
All design credits go to **Frontend Mentor**.

## 🛠 Technologies Used

- HTML5  
- CSS3  
- Flexbox  
- CSS Grid
- Dom Manipulation and arrays in javascript

---

## 🎯 Project Goals

- Practice cloning real-world website layouts  
- Improve CSS positioning and spacing  
- Build responsive sections (hero, features, footer)  
- Strengthen HTML structure and semantics  

---

## 📚 What I Learned

- Structuring complex landing page layouts  
- Combining Flexbox and Grid effectively  
- Improving responsive design techniques  
- Writing cleaner, more maintainable CSS
- Manipulating the webpage with javascript
